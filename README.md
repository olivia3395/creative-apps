# Creative Apps

A quiet collection of cinematic, atmospheric and emotionally resonant web apps: part digital keepsakes, part memory-keepers. Each folder is a self-contained Vite app with its own README. Every app was developed as a separate repository and moved here with its full commit history.

Browse them all on my homepage: [olivia3395.github.io/myapps](https://olivia3395.github.io/myapps/)

## Literature and art

| [Borrow a Better Sentence](borrow-a-better-sentence/) | [demo](https://borrow-a-better-sentence.vercel.app) | Rewrites everyday thoughts in the style of iconic writers. |
